01 · About the project

A creative exploration of avian evolution.

Project Chickensaurus is a fictional, speculative concept inspired by evolutionary biology, paleontology and the evolutionary history of birds.

Through imagined chicken-breed concepts, the project explores how selected dinosaur-inspired features could be represented in visual designs. Each concept is an opportunity to learn more about birds, theropods and the connections between them.

Project focus

From modern chickens to prehistoric inspiration.

The aim is to combine creative creature design with accessible science communication — while keeping real biology separate from fictional ideas.

Important project note

Project Chickensaurus is a fictional speculative project. It is not an actual genetic-engineering programme, and no real animals are being genetically modified. The concepts presented here are creative designs, not instructions or proposals for modifying living animals.
